# project-management-copilot
AI-powered Project Management Copilot using RAG, LLMs, and Agile delivery workflows.
## Overview
AI-powered Project Management Assistant that helps generate:

- Project status reports
- RAID logs
- Executive summaries
- Sprint summaries
- Stakeholder updates
- Risk assessments

## Technologies
- Python
- Streamlit
- OpenAI
- LangChain
- ChromaDB
- GitHub

## Features
- Upload project documents
- Ask project-related questions
- Generate executive updates
- Create RAID logs automatically
- Summarize sprint progress

## Roadmap
- Phase 1: Document Upload
- Phase 2: RAG Search
- Phase 3: LLM Responses
- Phase 4: Dashboard
